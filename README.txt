Math Combat - a text-based mathematics learning game
====================================================

Files in this folder (all four files must stay together):
  MathGame.exe           the game
  questions.txt          default question bank (8 topics x 10 questions)
  questions_teacher.txt  teacher question bank (edited in teacher mode)
  banks.txt              the list of question banks

How to run
  1. Double-click MathGame.exe.
  2. Type 1 for Student or 2 for Teacher, then press Enter.
  3. Student: enter your name, choose a topic, choose a question bank,
     answer 10 questions and fight the boss at the end.
  4. Teacher: enter your name, choose a topic and a question number,
     type the new question and answer. The change is saved to
     questions_teacher.txt automatically.

Notes
  - Windows 10 or Windows 11, no installation needed.
  - If the characters look strange, run the game in Windows Terminal.
  - Do not rename or move the three .txt files.

Version 1.0  (built with Microsoft Visual Studio, Release x64)
